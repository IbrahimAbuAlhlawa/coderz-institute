HTML Basics

كورس HTML Basics هو كورس للمبتدئين يعلّم الطلاب كيفية إنشاء صفحات الويب باستخدام لغة HTML. سيتعلم الطالب بناء هيكل الصفحة وإضافة العناوين والفقرات والصور والروابط والقوائم.

متطلبات الكورس

  • جهاز كمبيوتر أو لابتوب.
  • اتصال بالإنترنت.
  • متصفح ويب مثل Google Chrome.
  • محرر أكواد مثل Visual Studio Code.
  • لا يشترط وجود خبرات سابقة في البرمجة.
